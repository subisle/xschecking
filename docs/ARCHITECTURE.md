# 项目架构说明

## 架构概览

本项目采用经典的分层架构设计，遵循"安全流程驱动"的理念，为授权系统提供坚实的后端基础。

## 目录结构详解

### cmd/ - 应用入口
```
cmd/server/main.go
```
- 应用程序启动入口
- 负责初始化各个模块（配置、日志、数据库、Redis）
- 启动HTTP服务器

### internal/ - 内部包

#### config/ - 配置管理
- 使用 Viper 加载 YAML 配置
- 支持多环境配置（dev/prod）
- 配置结构体化，类型安全

#### model/ - 数据模型层
**核心模型：**
1. **User** - 用户模型
   - 邮箱唯一索引
   - 密码哈希存储
   - 状态管理（正常/冻结/封禁）
   - 登录追踪

2. **CaptchaToken** - 验证码通行证
   - 一次性凭证机制
   - IP和UA绑定
   - 防重放攻击

3. **EmailCode** - 邮箱验证码
   - 类型区分（注册/登录/重置）
   - 失败次数限制
   - 过期时间控制

#### pkg/ - 公共工具包
- **database.go** - GORM数据库连接和自动迁移
- **redis.go** - Redis客户端初始化
- **logger.go** - Zap日志初始化
- **jwt.go** - JWT生成和解析
- **response.go** - 统一响应格式
- **utils.go** - 通用工具函数（密码加密、随机字符串等）

#### middleware/ - 中间件层
按执行顺序：
1. **RequestID** - 生成唯一请求ID，用于追踪
2. **Logger** - 记录所有HTTP请求日志
3. **Recovery** - 捕获panic，防止服务崩溃
4. **CORS** - 处理跨域请求
5. **Auth** - JWT认证（按需使用）

#### router/ - 路由层
- 路由按业务域划分
- 清晰的路由分组
- 中间件灵活组合

#### handler/ - 控制器层
- 处理HTTP请求
- 参数验证
- 调用service层（待实现）
- 返回响应

#### service/ - 业务逻辑层（待实现）
- 核心业务逻辑
- 事务处理
- 调用repository层

#### repository/ - 数据访问层（待实现）
- 数据库操作封装
- 缓存操作
- 数据持久化

#### auth/ - 认证模块（待实现）
- 验证码服务
- 邮箱验证码服务
- 会话管理

#### risk/ - 风控模块（待实现）
- 登录风控
- 注册风控
- 行为分析

## 数据流向

### 请求处理流程
```
HTTP请求
  ↓
中间件链（RequestID → Logger → Recovery → CORS）
  ↓
路由匹配
  ↓
认证中间件（如需要）
  ↓
Handler（控制器）
  ↓
Service（业务逻辑）
  ↓
Repository（数据访问）
  ↓
Database/Redis
  ↓
响应返回
```

### 注册流程（设计）
```
1. 前端获取验证码
2. 用户填写表单
3. 提交注册请求
   ↓
4. 校验 captcha_pass_token
   ↓
5. 校验邮箱验证码
   ↓
6. 校验卡密（可选）
   ↓
7. 风控判断
   ↓
8. 创建用户
   ↓
9. 返回成功
```

### 登录流程（设计）
```
1. 前端获取验证码
2. 用户输入账号密码
3. 提交登录请求
   ↓
4. 校验 captcha_pass_token
   ↓
5. 验证用户名密码
   ↓
6. 风控检查
   ↓
7. 生成JWT Token
   ↓
8. 返回Token
```

## 安全设计

### 1. 验证码通行证机制
- **目的**：防止接口被跳过或重放
- **实现**：验证码校验成功后生成一次性token
- **使用**：注册/登录接口必须携带此token
- **销毁**：使用后立即失效

### 2. JWT会话管理
- **内容**：用户ID、登录时间、IP段、UA哈希
- **验证**：每次请求验证IP段和UA
- **过期**：可配置过期时间
- **刷新**：支持token刷新机制（待实现）

### 3. 密码安全
- **加密**：使用bcrypt加密
- **强度**：默认cost为10
- **存储**：只存储哈希值，不存储明文

### 4. 风控体系
- **登录风控**：失败次数限制、IP限制
- **注册风控**：频率控制、邮箱验证
- **行为分析**：异常行为检测（待实现）
